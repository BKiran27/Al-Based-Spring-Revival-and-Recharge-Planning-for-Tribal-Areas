## 🚀 Core Architecture & SecOps Lifecycle

CloudSentinel models the entire industry-standard cybersecurity incident response workflow:

```
[Normal Baseline] ──> [Suspicious Telemetry] ──> [AI Detection Engine]
                                                        │
┌───────────────────────────────────────────────────────┘
▼
[Proactive Alert Triggered] ──> [Threat Graph Correlation] ──> [Incident War Room]
                                                                        │
┌───────────────────────────────────────────────────────────────────────┘
▼
[1-Click Playbook Containment] ──> [Root Cause Eradication] ──> [Secure Recovery Baseline]
```

### Key Technical Pillars:
- **Autonomous State Engine**: Built with a reactive client-side database preserving mutations in browser local storage. Quarantining a server or disabling a compromised credential dynamically updates the risk engine across all dashboards.
- **CIS Benchmark v1.4 Posture**: Automated checks across IAM, Storage, Network, and Encryption with 1-click policy remediations.
- **Safe Malware Emulation Sandbox**: Calculates SHA-256 signatures, YARA heuristic scores, and MITRE ATT&CK techniques inside an isolated virtual container.
- **Explainable Mathematical Scoring**: Transparent, auditable formula calculating composite security posture from threat severity, asset criticality, and unmitigated exposure weights.
