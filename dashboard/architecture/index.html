Technical System Architecture & Data Flow

JUDGING REFERENCE

Complete technical blueprint illustrating how signals flow from cloud telemetry to automated incident containment.

LAYER 01•Frontend Presentation & Telemetry Deck
Next.js 14 App Router • TypeScript • Tailwind CSS • Lucide Icons • Recharts

Delivers a responsive, dark-first cybersecurity command center with a 10-step Judges Demo Mode, live SVG relationship graphs, and real-time polling.

LAYER 02•REST API Gateway & RBAC Layer
FastAPI • Pydantic v2 • JWT (PyJWT) • Bcrypt • CORS Middleware

Enforces fine-grained role-based access control across Admin, Security Analyst, Cloud Operator, and Viewer roles with token-based authentication.

LAYER 03•Security Engine & Ingestion Filter
Event Ingestion Pipeline • Normalization • Anomaly Heuristics

Ingests raw telemetry across compute instances, storage buckets, and IAM events, classifying signals into standardized SecOps schemas.

LAYER 04•Real-Time Threat Detection & Correlation
Rule Evaluator • Behavioral Anomaly Detector • Confidence Scorer

Correlates multi-source events to identify Account Takeover, Impossible Travel, Privilege Escalation, and Data Exfiltration with 90%+ confidence.

LAYER 05•Explainable Risk Scoring Engine
Deterministic Mathematical Formulation (Identity + Threat + Network + Asset)

Calculates real-time risk scores from 0-100 without black-box obscurity, itemizing exact positive and negative point deltas for evaluators.

LAYER 06•Incident Response & Containment Orchestrator
NIST SP 800-61 Workflow • Automated Host & Token Quarantine

Executes 1-click containment playbooks: terminating active JWTs, isolating compromised VMs into quarantine subnets, and dropping firewall IPs.

LAYER 07•Relational Persistence & Audit Trail
SQLAlchemy 2.0 ORM • SQLite (WAL Mode) / PostgreSQL Dual Support

14 relational tables storing users, resources, events, proactive alerts, threats, war room actions, malware scans, and immutable audit logs.
